VEROEFFENTLICHUNG UEBER GITHUB.COM
----------------------------------
1. Bei https://github.com mit BertSing anmelden.
2. Oben rechts auf das Pluszeichen und dann auf "New repository" tippen.
3. Repository name: bertholds-kochbuch
4. "Public" waehlen.
5. "Add a README file" NICHT aktivieren.
6. Auf "Create repository" tippen.
7. Im neuen Repository "uploading an existing file" waehlen.
8. Den INHALT dieses Ordners hochladen, nicht die ZIP-Datei selbst.
9. Unten "Commit changes" bestaetigen.
10. Im Repository Settings > Pages oeffnen.
11. Unter Build and deployment: Source = "Deploy from a branch".
12. Branch = main, Folder = /(root), danach Save.
13. Nach einigen Minuten ist die Seite erreichbar unter:
    https://bertsing.github.io/bertholds-kochbuch/
