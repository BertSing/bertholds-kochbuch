BERTHOLD'S KOCHBUCH – PHASE 1
==============================

Enthalten sind drei Ersatzdateien:
- index.html
- assets/style.css
- assets/app.js

So wird die neue Startseite veröffentlicht:
1. Auf GitHub das Repository BertSing/bertholds-kochbuch öffnen.
2. "Add file" > "Upload files" wählen.
3. Den INHALT dieses Ordners hochladen.
4. Bei Rückfrage die vorhandenen Dateien index.html und assets/style.css ersetzen.
5. "Commit changes" bestätigen.

Wichtig:
Die vorhandenen Ordner "rezepte" und "friedas-rezepte" werden nicht gelöscht.
Dadurch bleiben alle bestehenden Rezeptlinks erhalten.

In Phase 1 umgesetzt:
- modernisierte Startseite
- mobile Navigation
- verbesserte Live-Suche
- Kategorien und Filter
- Hell-/Dunkelmodus
- Druckansicht
- barriereärmere Bedienung
- bestehende Rezept-URLs unverändert
